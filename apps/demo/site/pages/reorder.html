List reorder

A comment belongs to the item, not to li:nth-child(3).
  1. Comment on Kiwi (the third row).
  2. Press Shuffle or Sort A→Z. The badge follows Kiwi.
  3. Press Remove Kiwi. The thread orphans and its badge docks to the corner.
  4. Press Restore. It re-anchors — watch thread:anchored in the log.
Rows deliberately have no id: position and CSS path are both worthless here, so the match has to come from the fingerprint and the row's own text.

Why the demo no longer raises anchoring.threshold (see assets/demo.js). After a shuffle the stored CSS selector #list > li:nth-of-type(3) still matches — it now points at whoever moved into that slot. That wrong row used to score ≈0.76, because tag, classes, depth and shape all still matched and only the text differed, which was worth 0.12 of a weighted average; the page defended itself by demanding 0.9 of every match. The text digest is now a verifier rather than a fifth contribution (SPEC §2.5, decision log #26), so a row that nothing identifies and whose text disagrees scores 0 at any threshold, the fingerprint scan runs, and it finds the real row at 1.00. The demo is back on the library's own 0.62.
